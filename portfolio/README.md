# Aedin Richardson — Portfolio

Personal site for [Aedin Richardson](https://github.com/Alteoziel). The app lives in this `portfolio/` directory.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- GitHub API (hourly revalidation) for project cards, with curated copy for empty repo descriptions

Featured work includes [Alte' Budgeting](https://github.com/Alteoziel/Budget-App).

## Local

```bash
cd portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

On Vercel, set the **Root Directory** to `portfolio`.
